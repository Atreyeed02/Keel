Event store

Event log

Every account opened and every transaction posted is also written here as an {{ ui.term("event", "event") }}, in the same database transaction. This is the ledger's history, newest first.

How the event log works

Events are never changed

The database refuses to change or delete an event. So nothing is edited: to fix a mistake, post a {{ ui.term("balanced", "balanced") }} transaction with the same entries on the opposite sides, then post the right one.

{%- if reversal %} {#- An example, never posted: a dashed box, with no number, time or marker. -#}

For example, undoing February's rent (No. {{ reversal.number }}) would be:

The tables are rebuilt from it

The balances on the overview and the transaction list are read from tables kept beside this log. They can be thrown away and rebuilt by replaying these events in order, oldest first, and they come back the same.

{%- if is_demo() %}

On this demo, the nightly reset is the one exception: it empties the log and the tables together and starts again from the demo data.

{%- endif %}
